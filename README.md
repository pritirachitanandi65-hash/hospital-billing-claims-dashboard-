# Hospital Billing & Claims Optimization Dashboard

## 📌 Project Overview

The Hospital Billing & Claims Optimization Dashboard is a Power BI analytics project designed to analyze hospital billing, revenue, unbilled services, payment delays, and insurance claims.

The dashboard helps identify revenue leakage, delayed payments, claim denials, and high-risk unbilled services to support better financial decision-making.

---

## 🎯 Project Objective

The main objectives of this project are:

- Analyze hospital billing and revenue performance.
- Identify unbilled services and potential revenue leakage.
- Monitor payment delays and payment lag.
- Analyze insurance claims and claim status.
- Identify claim rejection and denial reasons.
- Highlight high-risk unbilled services.
- Provide actionable insights through interactive Power BI dashboards.

## 📊 Dataset

The project uses a realistic synthetic hospital dataset containing information related to:

- Patient and visit information
- Billing and revenue
- Insurance claims
- Payment information
- Claim status
- Claim denial reasons
- Billing dates
- Submission and resolution dates

The data is synthetic and created for analytics and demonstration purposes.

---

## 🔄 Project Workflow

The project follows these main steps:

1. Generate synthetic hospital data using Python.
2. Store and manage the data using SQL/SQLite.
3. Clean and prepare the data for analysis.
4. Connect the data to Power BI.
5. Create DAX measures and calculated fields.
6. Build interactive dashboards.
7. Analyze revenue leakage, billing delays, and claims.
8. Generate business insights for decision-making.

### Page 3 — Insurance Claims Analysis

This page provides detailed claim-level information for deeper analysis and investigation.
